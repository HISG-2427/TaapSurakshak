# TaapSurakshak

**Predict Heat. Protect Lives.**

TaapSurakshak is a smart heat-risk monitoring and emergency response platform designed to help cities identify heatwave risks and protect vulnerable communities.

## Features

- Heat-risk monitoring dashboard
- Regional heatmaps
- Mortality-risk analysis
- Hospital-capacity monitoring
- Predictive risk visualization
- Emergency alert management
- User signup and login
- MongoDB-based data storage

## Technologies Used

- Node.js
- Express.js
- EJS
- EJS-Mate
- MongoDB
- Mongoose
- Bootstrap
- Leaflet
- Chart.js
- bcrypt
- Express-session
